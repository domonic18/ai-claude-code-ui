## 1. 背景与问题

当前侧边栏存在以下交互缺陷：

| # | 问题 | 严重程度 |
|---|------|---------|
| 1 | 新建空项目后，侧边栏不显示该项目，用户无法确认创建是否成功 | 高 |
| 2 | 项目删除按钮仅当 sessionCount === 0 时才出现，有对话的项目无法删除 | 中 |
| 3 | 项目行的操作按钮（编辑/删除）缺少统一的入口（三点菜单） | 低 |
| 4 | 后端将 `/workspace` 下所有条目（含文件如 `node-test-file.txt`）都识别为项目 | 低（暂不处理） |

本文档定义侧边栏**项目**和**对话**两层结构的完整交互规范，作为后续实现的依据。

---

## 2. 核心概念

### 2.1 项目（Project）

- **定义**：容器内 `/workspace` 目录下的每个子目录即为一个项目
- **对应关系**：项目 = 工作区，上传的文档、Claude 会话、项目配置（`CLAUDE.md`）都属于当前项目
- **生命周期**：用户主动创建 → 使用（对话/上传文档）→ 用户主动删除

### 2.2 对话（Session）

- **定义**：一个项目下的单次 AI 会话（由 Claude/Cursor/Codex 创建）
- **归属**：每个对话属于且仅属于一个项目
- **生命周期**：用户发消息时自动创建 → 使用 → 用户主动删除

## 3. 侧边栏交互规范

### 3.1 整体结构

```
┌─ 侧边栏 ──────────────────────────────┐
│  [+ 新建项目]               [🔄 刷新]   │
│                                        │
│  ── 项目（可展开/折叠）────────────────  │
│  📁 我的工作区              [+]  [⋯]    │  ← 项目行
│    ├ 💬 昨天的对话         [✏️] [🗑️]    │  ← 对话行
│    ├ 💬 代码审查           [✏️] [🗑️]    │
│    └ 💬 bug修复            [✏️] [🗑️]    │
│                                        │
│  📁 新项目（空的）          [+]  [⋯]    │  ← 空项目也显示
│                                        │
│  📁 test-project           [+]  [⋯]    │
│    └ 💬 单元测试          [✏️] [🗑️]    │
└────────────────────────────────────────┘
```

### 3.2 项目行交互

#### 3.2.1 常态显示

| 元素 | 显示规则 |
|------|---------|
| 项目图标 + 名称 | 始终显示 |
| 展开指示器 ▶/▼ | 始终显示 |
| `[+]` 新对话按钮 | 鼠标悬停时显示（`opacity` 过渡） |
| `[⋯]` 三点菜单 | 鼠标悬停时显示（`opacity` 过渡） |

#### 3.2.2 三点菜单 `[⋯]`

点击后弹出下拉菜单，包含：

| 菜单项 | 图标 | 说明 |
|--------|------|------|
| 重命名 | ✏️ | 进入内联编辑模式 |
| 删除 | 🗑️ | 弹出确认弹窗 |

> **注意**：无论项目是否有对话，都显示「删除」选项。删除操作是**不可逆**的（删除整个目录）。

#### 3.2.3 新对话按钮 `[+]`

- 点击后在当前项目下创建新对话
- 自动选中该项目，主区域切换为空白聊天界面
- 项目自动展开（如果之前是折叠的）

#### 3.2.4 点击项目名称

- **已折叠**：展开项目，加载对话列表
- **已展开**：选中该项目，主区域切换到该项目视图
- **空项目**：选中之，主区域显示空白聊天界面，用户可直接发消息

### 3.3 对话行交互

#### 3.3.1 常态显示

| 元素 | 显示规则 |
|------|---------|
| 对话图标 + 名称（summary） | 始终显示 |
| 活跃指示器（绿色脉冲） | 最近 10 分钟内有消息时显示 |
| `[✏️]` 编辑按钮 | 鼠标悬停时显示 |
| `[🗑️]` 删除按钮 | 鼠标悬停时显示 |

#### 3.3.2 编辑对话名称 `[✏️]`

- 点击后切换为内联 `<input>` 输入框
- Enter 或点击 ✓ 保存 → 调用 `PATCH /api/projects/:name/sessions/:id` 更新 summary
- Escape 或点击 ✗ 取消

#### 3.3.3 删除对话 `[🗑️]`

- 点击后弹出确认弹窗
- 确认后调用 `DELETE /api/projects/:name/sessions/:sessionId`
- 删除后如果项目变为空项目，项目仍保留在侧边栏

#### 3.3.4 点击对话

- 选中该对话，主区域加载对话消息历史

## 4. 操作流程详述

### 4.1 新建项目

```
用户点击 [+ 新建项目]
  ↓
弹出创建向导（输入项目名称 + 可用性检查）
  ↓
用户点击 [创建]
  ↓
① 后端创建 /workspace/{projectName} 目录
② 前端刷新项目列表（force，跳过去重缓存）
③ 侧边栏立刻显示新项目（空项目，无对话）
④ 自动选中新项目，主区域显示空白聊天界面
⑤ 弹窗关闭
  ↓
用户可直接在聊天框输入消息开始对话
```

**关键规则**：
- 新项目无论是否有对话，都必须在侧边栏可见
- 创建完成后自动选中并展开
- 刷新时使用 `force: true` 绕过 `requestDeduplicator`，确保拿到最新数据

### 4.2 删除项目

```
用户悬停项目行 → 点击 [⋯] → 点击 [删除]
  ↓
弹出确认弹窗：
  标题：「删除项目 "{projectName}"」
  警告：「此操作将永久删除该项目及其所有对话，不可恢复。」
  按钮：[取消] / [确认删除]（红色危险按钮）
  ↓
用户点击 [确认删除]
  ↓
① 后端执行 rm -rf /workspace/{projectName}
② 前端从项目列表移除该项目
③ 如果删除的是当前选中项目 → 清空选中状态，主区域显示欢迎页或切换到第一个项目
```

**关键规则**：
- 无论项目是否有对话都可以删除（与当前实现不同，当前只允许空项目删除）
- 删除前必须弹出确认弹窗
- 删除当前正在使用的项目时，自动切换到其他项目或显示空状态

### 4.3 重命名项目

```
用户悬停项目行 → 点击 [⋯] → 点击 [重命名]
  ↓
项目名称切换为 <input> 编辑态
  ↓
用户输入新名称 → Enter 或点击 ✓
  ↓
① 调用 API 更新 displayName（注意：只改显示名，不改目录名）
② 前端乐观更新侧边栏中的项目名称
```

### 4.4 新建对话

```
用户悬停项目行 → 点击 [+]
  或
用户点击顶部 [新建会话] 按钮（在当前选中的项目下新建）
  ↓
① 清空当前选中的对话
② 主区域切换为空白聊天界面
③ newSessionCounter +1（触发新会话创建）
```

### 4.5 文档与项目的关系

- 用户上传的文档存储在当前项目目录下
- 文档与项目绑定，切换项目时文档列表同步切换
- 删除项目时，其下所有文档一并删除（不可逆）

## 5. 现有实现对照

### 5.1 已实现 ✅

| 功能 | 实现位置 |
|------|---------|
| 项目创建（API + 前端向导） | `POST /api/projects/create` → `ProjectCreationWizard` |
| 项目重命名（内联编辑） | `ProjectCardDesktop` → `useProjectEditHandlers` |
| 项目删除（仅空项目） | `QuickActions` → `handleDeleteProject` |
| 对话列表加载（无限滚动） | `SessionList` → Intersection Observer |
| 对话重命名（内联编辑） | `SessionItem` → `SessionItemRenaming` |
| 对话删除（确认弹窗） | `SidebarModals` → `ConfirmDialog` |
| 收藏项目（Star） | `QuickActions` → `toggleStar` |
| 项目列表排序（多种排序 + 手动拖拽） | `projectSortHelpers` |

### 5.2 需要修改 ❌

| 功能 | 当前状态 | 需要改为 |
|------|---------|---------|
| 空项目不显示 | 渲染层过滤了空项目 | 空项目始终显示，点击后开始新对话 |
| 项目删除仅限空项目 | `QuickActions` 中 `sessionCount === 0` 才显示删除按钮 | 无论有无对话都显示删除 |
| 项目操作分散 | 编辑和删除是独立图标 | 统一为 `[⋯]` 三点菜单，含重命名和删除 |
| 刷新被去重吞掉 | `executeSidebarRefresh` 使用 `requestDeduplicator` | 创建后用 `force: true` 跳过去重 |
| 生产模式无日志 | `drop_console: true` + `logger` 为空函数 | 修复 bug 后恢复 `drop_console: true` |

# 第一部分：快速入门

## 1. 系统简介

### 1.1 什么是 Claude Code UI

Claude Code UI 是一个为专利从业人员设计的 **AI 辅助文档生成平台**。它基于 Claude AI 模型，通过强大的 **Extensions 扩展系统**，帮助您：

- **快速生成专利文档**：技术交底书、权利要求书、商业价值分析等
- **撰写技术方案**：系统架构、实施方案、可行性评估
- **产出学术论文**：工程论文、科学论文、经济论文
- **处理文档格式**：PDF、Word、PowerPoint 文档的智能处理

### 1.2 核心功能概览

| 功能模块 | 说明 |
|---------|------|
| **智能对话** | 与 Claude AI 进行自然语言交互 |
| **Extensions 系统** | 预置的专业文档生成技能（Skill） |
| **Skill 选择器** | 聊天工具栏一键选择要使用的技能 |
| **项目管理** | 多会话管理 |
| **文件浏览器** | 可视化项目文件管理 |
| **内置终端** | 容器隔离的安全执行环境 |

## 3. 5分钟快速上手

### 3.1 用 Skill 生成第一份文档

生成文档的标准方式是**先选技能，再输入需求**：

1. 在聊天输入框上方的工具栏，找到 **Skill** 按钮（⚡ 图标）
2. 鼠标移上去 → 出现分类列表 → 悬停某个分类（如"学术论文"）→ 右侧弹出该分类下的技能 → 点击想要的技能（如"工程论文"）
3. 按钮上会显示已选技能名称，然后在输入框写明你的需求并发送

```
（已选：工程论文）
主题：基于物联网的智能绿植监测系统
```

AI 会用你选定的技能生成文档，保存到右上角 files 标签页中的 `generated_docs/` 目录。

### 3.2 查看生成的文件

1. 点击右侧的 **files** 标签
2. 展开 `generated_docs/` 目录
3. 找到生成的 Markdown 文件，点击查看

## 5. 聊天与AI交互

### 5.1 Ctrl+Enter 发送模式

可在设置中开启，需要按 Ctrl+Enter 才发送。

### 5.2 Skill 选择器

聊天工具栏的 **Skill** 按钮（⚡）用于选择本次消息使用的技能，详见 [10. 使用 Skill 生成文档](#10-使用-skill-生成文档)。

### 5.3 文件引用

在对话中引用项目文件：

```
请分析 @generated_docs/requirement.md 中的内容
```

系统会：
1. 自动提示匹配的文件
2. 选中文件后自动插入引用
3. AI 获取文件内容进行分析

### 5.4 文件附件

支持上传文件并发送给 AI：

1. 点击输入框旁的 📎 图标
2. 选择本地文件
3. 文件会显示在预览区
4. 发送消息时一并提交

### 5.5 权限模式

点击权限模式按钮可切换：

| 模式 | 说明 |
|------|------|
| **默认** | AI 操作需要手动确认 |
| **接受编辑** | 自动接受文件编辑操作 |
| **绕过权限** | 不执行权限检查（谨慎使用） |
| **计划模式** | 仅规划操作，不执行 |

# 第三部分：Skill 与文档生成

## 9. Skill 与 Agent 概述

本系统提供两类文档生成能力：

| 概念 | 说明 | 如何触发 |
|------|------|----------|
| **Skill（技能）** | 单一专业能力模块，如"写工程论文""写产品方案" | 你在工具栏 **主动选择** |
| **Agent（代理）** | 工作流编排器，自动调用多个 Skill 完成多阶段任务 | 自然语言描述，系统识别意图 |

> **重要**：日常单篇文档生成**完全由你主动选 Skill**，系统不做意图识别。**意图识别目前只保留给批量生成 Agent**——只有你说"批量生成"时，系统才会自动路由到批量 Agent 编排。

### 9.1 生成文档的两种方式

**方式一：选 Skill 直出（推荐，最常用）**

通过工具栏 Skill 按钮选择具体技能，再输入需求。优点：
- ✅ 你完全掌控用哪个技能，结果可预期
- ✅ 适合生成单篇文档（论文、方案、交底书等）

**方式二：批量生成（Agent 编排）**

用自然语言描述批量需求，系统自动调用 `batch-patent-generator` 编排"论文 → 创意挖掘 → 单创意文档生成"的完整管线。适合一个创意批量产出多篇文档。

### 9.2 Skill 分类速览

Skill 按分类组织（分类与列表由后端 Extensions 系统下发）：

| 分类 | 典型技能 |
|------|---------|
| **专利文档** | 技术交底书、权利要求撰写、说明书撰写、专利合规审查等 |
| **商业战略** | 商业价值分析、IP 保护策略、产品方案、运营方案等 |
| **技术文档** | 技术方案、价值主张、立论白皮书、可行性评估等 |
| **学术论文** | 工程论文、科学论文、经济论文 |
| **工具** | 文档审核、PDF / Word / PPT 处理等 |

> 具体可用技能以工具栏 Skill 菜单里实际显示的为准。

## 10. 使用 Skill 生成文档

### 10.1 选择 Skill

1. 在聊天输入框上方的工具栏找到 **Skill** 按钮（⚡ 图标，位于权限模式按钮左侧）
2. **鼠标移到按钮上**，弹出分类菜单（一级）
3. **悬停某个分类**，右侧弹出该分类下的技能列表（二级）
4. **点击想要的技能**即选中，按钮上会显示该技能名称

> 提示：菜单是悬停触发的，鼠标移开后会自动收起。

### 10.2 选中后的行为

- **仅作用于下一条消息**：选中的技能会随你发送的下一条消息一起生效，**发送后自动清除**（一次性）
- **按钮显示当前技能**：选中后按钮变紫并显示技能名，方便确认
- **清除选择**：点击按钮右侧的 ✕，或再次点击同一技能，即可取消
- **不选也能用**：不选任何 Skill 时，AI 会作为通用助手直接回应你的消息

### 10.3 使用示例

**生成一篇工程论文：**
1. Skill 按钮 → 悬停"学术论文" → 点击"工程论文"
2. 输入框输入：`主题：基于联邦学习的隐私保护推荐系统`
3. 发送 → AI 用该技能生成论文 → 保存到 `generated_docs/`

**生成一份产品方案：**
1. Skill 按钮 → 悬停"商业战略" → 点击"产品方案"
2. 输入框输入：`基于以下专利生成产品方案：[粘贴专利内容]`
3. 发送

## 11. 批量专利生成（Agent 编排）

当需求是"一个创意批量产出多篇文档"时，用自然语言触发批量 Agent，系统会自动编排两阶段管线：

```
用户输入创意
       ↓
┌──────────────────────────────────────────┐
│  batch-patent-generator（前置阶段）       │
│  • 生成三篇论文（工程 / 科技 / 经济）     │
│  • 创意挖掘（约 10 个可专利创意）         │
│  • 返回结构化创意清单                     │
└──────────────────────────────────────────┘
       ↓  逐个创意分发
┌──────────────────────────────────────────┐
│  single-creative-generator（每个创意）    │
│  • 3 个专利文件：权利要求书 / 说明书 /     │
│    摘要与附图说明                          │
│  • 4 个配套方案：产品 / 技术 / 运营 / IP   │
│  （共 7 个文档 × N 个创意）               │
└──────────────────────────────────────────┘
       ↓
输出到 generated_docs/输入创意_[时间戳]/
```

**触发方式**：直接用自然语言描述批量需求（无需选 Skill）：

```
批量生成专利：AI绿植健康管家

批量生成专利，创意如下：
1. AI绿植健康管家SaaS
2. 跨境电商差评预警工具
3. 智能简历优化系统
```

**输出**：所有文件输出到 `generated_docs/输入创意_[时间戳]/`，每个创意产出 7 个文档（3 专利 + 4 方案）。详见 Extensions 系统的《智能专利系统使用手册》。

## 12. 常见问题 FAQ

### Q1: 一定要先选 Skill 才能生成文档吗？

**A**: 单篇文档生成建议先选 Skill，这样结果最可控。如果不选，AI 会作为通用助手直接回应，但不会套用特定技能的规范和格式。

### Q2: 选错的 Skill 怎么办？

**A**: 点击按钮右侧的 ✕ 清除，或直接选另一个技能即可。选中的技能只作用于下一条消息，发送后自动清除，不会影响后续对话。

### Q3: 如何查看生成的文档？

**A**: 有两种方式：
1. 在聊天界面查看（AI 会显示内容摘要）
2. 在文件浏览器中打开完整文件（右上角 files 标签），展开 `generated_docs/` 目录

### Q4: 生成的文档可以直接使用吗？

**A**: 生成的文档是高质量草稿，建议：
1. 仔细审核技术内容的准确性
2. 补充具体的实验数据
3. 由专业专利代理人最终审核
4. 根据实际需求调整格式

### Q5: 如何引用已有文档生成新文档？

**A**: 使用文件引用：

```
请参考 @existing_doc.md 生成新的技术交底书

基于 @tech_proposal.md 生成完整的专利申请文档
```

### Q6: 生成的文档太简单怎么办？

**A**：

**原因**：输入信息不够详细

**解决**：
```
请重新生成，补充以下信息：
发明名称：基于物联网的智能健康监测水杯
技术背景：现有水杯功能单一，无法监测饮水量、水温、水质...
技术方案：集成温湿度传感器、水质检测模块、蓝牙通信模块...
实施方式：传感器采集 → 微控制器处理 → 蓝牙传输 → 手机APP显示
有益效果：帮助用户养成健康饮水习惯，预防水质问题...
```

### Q7: 单篇生成和批量生成怎么选？

**A**:
- **单篇**：明确知道要哪一种文档（如只要一篇工程论文）→ 选 Skill 直出
- **批量**：想从一个创意衍生出多篇论文 + 多个可专利创意 + 每个创意全套文档 → 自然语言触发批量 Agent

## 13. 总结

1. **单篇生成先选 Skill**：工具栏 Skill 按钮主动选择，结果可控、可预期
2. **批量生成用自然语言**：说"批量生成"即触发 Agent 编排
3. **提供足够的输入信息**：信息越详细，生成质量越高
4. **保存好版本**：每次生成都会保存到 `generated_docs/`，方便对比和回溯
5. **人工审核把关**：AI 是辅助，最终需要专业审核


如果遇到问题：
1. 在聊天中直接询问 AI："有哪些文档生成功能？"
2. 查看本文档的相关章节
